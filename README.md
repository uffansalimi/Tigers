# London Tigers 3rd XI Stats

Batting, bowling, head-to-head and season-by-season stats for London Tigers CC 3rd XI, 2022–2026.

The whole site is one file, `index.html`, with the stats built in. It is published with GitHub Pages at
https://uffansalimi.github.io/tigers/

Sources: 2022–2024 from match-by-match records kept by Uffan; 2025–2026 from the London Tigers CC play-cricket site (3rd XI), plus Uffan's own additions for 2025.
